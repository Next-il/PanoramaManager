# Examples

Three plugins, each showing one thing. All reference `PanoramaManager` and nothing else.

| | |
|---|---|
| [`AdminMenu`](AdminMenu) | The row pool: player list, pagination, per-row callbacks, one central authorisation gate. Start here |
| [`AdminMenuKit`](AdminMenuKit) | The same menu on a different skin. Exists to prove a point - the diff is a layout path, `RevealClass` and `SetVariant`, and the rest of the C# is identical |
| [`TextInput`](TextInput) | Getting typed text out of a player, which a layout cannot do on its own |

They are examples, not products. Read them, copy the shape, delete them.
